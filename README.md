Zero-Budget Rules


تا زمانی که پروژه درآمد واقعی ایجاد نکرده است:




از سرویس‌های رایگان و Free Tier استفاده می‌شود.


هیچ VPS یا سرور اختصاصی الزامی نیست.


هیچ GPU اختصاصی الزامی نیست.


Blockchain Mainnet در Phase 0 فعال نمی‌شود.


خرید تبلیغات اجباری نیست.


خرید بازدید، لایک، کامنت یا عضو ممنوع است.


حساب‌های جعلی برای افزایش آمار ساخته نمی‌شوند.


رشد پروژه بر پایه کاربران و تعامل واقعی خواهد بود.




Success Criteria


Phase 0 زمانی موفق محسوب می‌شود که:




هویت رسمی MOLIDO تثبیت شده باشد.


کانال‌های رسمی فعال باشند.


انتشار منظم محتوا آغاز شده باشد.


اولین کاربران واقعی وارد Community شده باشند.


سیستم تولید و کنترل محتوای روزانه آماده باشد.


پایه فنی پروژه در GitHub ثبت و قابل توسعه باشد.




Phase 0 هدف مالی ندارد؛ هدف آن ساخت اعتماد، مخاطب واقعی و پایه قابل توسعه MOLIDO است.
