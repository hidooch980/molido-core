# The supervisor's job

Everything that can run on a schedule does. What is left is listed here, and
it is short on purpose.

## Every day — about a minute

1. Open **docs/TODAY.md**. It has the day's titles and post text in Persian
   and English, rewritten automatically each morning.
2. Download the two videos from the newest run under the **Actions** tab.
3. Upload one to YouTube, paste the matching title and description.

If Telegram posting is switched on (docs/AUTOMATION.md), step 3 covers
YouTube only — Telegram has already gone out.

## Every week — about five minutes

Look at two numbers in YouTube Studio, and only these two:

- **average percentage viewed** — above ~70% means the format works
- **link clicks** — if views are fine but clicks are zero, the problem is the
  call to action, not the video

Views on their own tell you very little this early.

## When docs/TODAY.md warns you

It counts how many days of written signals remain and warns at three. That
warning is the one recurring obligation no schedule can absorb: the pipeline
renders and posts, but it cannot invent new story.

Writing a week takes about twenty minutes. See docs/DAILY.md.

## The decision, after fourteen days

Set this rule now, while it is still cheap to be honest about it.

- **Five or more real people solved the puzzle and shared a result** — the
  format works. A backend for XP and collection is now worth its cost.
- **Nobody came** — the problem is not the code. Change the content or the
  channel. Building another feature reproduces the same zero, more
  expensively.

Write the number down on day fourteen before deciding. Deciding from memory
turns a flat result into "it was probably fine".

## What stays manual, permanently

Replying to people. Judging which title worked. Noticing that a community
finds the tone off. Deciding what the story does next.

That is the actual supervisor role, and it is the part that decides whether
this works. The automation exists so that none of your attention is spent on
rendering videos instead.
