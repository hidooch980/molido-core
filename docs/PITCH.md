# Introducing the project

Ready-to-use copy. Lead with the puzzle, never with the vision.

## The rule

Describe what exists today: a daily puzzle, a story in eight languages, no
accounts, free. Not the roadmap. Blockchain, AI assistants, XP and the
economy are documents, not features, and describing them as if they exist
breaks the project's own rule in the README — and the first person who
clicks through and finds none of it stops trusting the rest.

The vision is why *you* are building it. It is not why a stranger clicks.

## Posting in a community

Ask a question. Do not announce anything.

    I built a daily puzzle where you decode fragments of a transmission.
    Today: four stations recorded a block, and exactly one value appears
    in all four. Find it.

    Four puzzle types rotate weekly, so it is not the same trick every day.
    No account, nothing to install.

    How many tries did today take you?

The last line matters. It gives people something to reply with, and a thread
with replies is what the platform shows to other people.

## Show HN

    Show HN: A daily signal-decoding puzzle in 8 languages, no accounts

Body: what it is in two sentences, then how it is built — deterministic
per-day generation from a seeded PRNG, a test that proves every puzzle has
exactly one valid answer, static hosting at zero cost. That audience cares
about how, and the how is genuinely unusual here.

## What kills it

Do not open with "a global AI-powered digital ecosystem built around
interactive storytelling, games, community, creativity and future
decentralized technology". It is accurate about the ambition and it tells a
stranger nothing they can act on.

Compare:

- "MOLIDO is a global digital universe" — nobody can picture this
- "One value is missing from this transmission. Find it." — anybody can

Both are true. Only one earns the click.
